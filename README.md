- 本地儲存體力、體力上限、每點恢復分鐘數
- 依經過時間推算體力與滿體力時間（非官方即時資料）

- 完全離線，不要求遊戲帳密

## 只有 Android 手機的安裝流程
1. 在 Android 手機安裝可編譯 Android Gradle 專案的 IDE，例如 AndroidIDE。請從其官方網站／官方專案頁確認版本與安裝方式。某些 AndroidIDE 版本已停止維護，與新 Android 版本可能不相容。
2. 解壓 GamePilot-v0.1.zip，將整個 `GamePilot-v0.1` 資料夾放到手機可存取的位置。
3. 在 IDE 中選擇「Open project / 開啟專案」，選擇包含 `settings.gradle` 的 `GamePilot-v0.1` 資料夾。
4. 第一次使用時依 IDE 指示安裝 JDK 17、Android SDK Platform 34、Gradle 8.2.1（或相容版本）。Gradle 首次同步需要網路下載 Android Gradle Plugin 8.2.2。
5. 執行 Gradle Sync，接著執行 `:app:assembleDebug`。成功後 APK 一般位於 `app/build/outputs/apk/debug/app-debug.apk`。
6. 在手機檔案管理員開啟 APK，允許該來源安裝應用程式，然後安裝。
7. 第一次啟動允許通知；選遊戲、輸入遊戲內實際體力、儲存並設定提醒。

## 重要說明
- **本專案沒有在此環境完成 Android SDK 實機編譯驗證。** 若 IDE 報 Gradle/SDK 錯誤，請保留完整錯誤訊息供修正。
- 內建體力規則只是可編輯的初始值，不代表兩款遊戲所有版本的實際規則。尤其有體力溢出、儲備體力、活動加成、道具補充時，請手動校正。
- 本版本採用簡化整數恢復模型；手動儲存會重設恢復計時起點，因此長期估算可能與遊戲有差距。
- Android 的鬧鐘／省電機制可能延遲通知；手機重啟後須重新設定提醒。
- 本專案不會自動操作任何遊戲，也不包含繞過反作弊的功能。
